# LearnGraph Frontend

React frontend for the LearnGraph adaptive learning platform — personalized Chemistry learning for Indian high school students (Classes 11 & 12, NCERT-aligned).

## Tech Stack

| Layer | Technology |
|---|---|
| Framework | React 19 + TypeScript |
| Build Tool | Vite 8 |
| Routing | TanStack React Router (file-based) |
| Server State | TanStack React Query |
| Client State | Zustand (with localStorage persistence) |
| HTTP Client | Axios |
| Styling | Tailwind CSS 3 + CSS variables |
| Graph Viz | react-force-graph-2d |
| Icons | lucide-react |
| Notifications | react-hot-toast |

## Prerequisites

- Node.js >= 18
- npm >= 9
- The [LearnGraph backend](../learngraph-backend/) running (see its README)

## Setup

### 1. Install dependencies

```bash
npm install
```

### 2. Configure environment variables

Create a `.env` file in the project root:

```env
VITE_API_URL=http://localhost:3700
```

Change the URL if your backend runs on a different host or port.

### 3. Start the dev server

```bash
npm run dev
```

The app runs at `http://localhost:5174` by default (Vite auto-selects the port).

## Application Flow

```
/ (entry)
  └── Enter name + select class level (11 or 12)
      └── Backend creates/finds student
          └── Redirects to /learn

/learn (dashboard)
  ├── Chapter list with progress indicators
  ├── Click chapter → subtopic list (locked/unlocked/complete)
  ├── Start session → AI generates passage + 5 MCQs
  ├── Answer questions → submit
  └── Results: score, grade, mastery delta, knowledge gaps

/graph (knowledge graph)
  ├── Force-directed graph of all Chemistry chapters
  ├── Nodes colored by mastery level
  ├── Click node → chapter details in sidebar
  └── Recommendations for next chapters to study
```

## Routes

| Path | Description | Protection |
|---|---|---|
| `/` | Student entry screen | Public |
| `/learn` | Learning dashboard and quiz | Requires student in store |
| `/graph` | Knowledge graph visualization | Requires student in store |

Protected routes redirect to `/` if no student is found in the Zustand store.

## State Management

**Zustand store** (`src/store/student.store.ts`) persists to `localStorage` under the key `learngraph-student`:

```ts
{
  student: Student | null,   // current student object (id, name)
  classLevel: number,        // 11 or 12 (default: 12)
  setStudent(student),
  clearStudent(),            // used by sign-out
  setClassLevel(level),
}
```

**TanStack React Query** handles server state — caching, refetching, and loading states for API calls.

## API Integration

All API calls are defined in `src/lib/api.ts`. The base URL is read from `VITE_API_URL`:

| Function | Method | Endpoint |
|---|---|---|
| `studentApi.findOrCreate(name)` | POST | `/api/students` |
| `studentApi.getById(id)` | GET | `/api/students/:id` |
| `subtopicApi.getAllChaptersProgress(...)` | GET | `/api/subtopics/all-progress` |
| `subtopicApi.getChapterProgress(...)` | GET | `/api/subtopics/:topicId/progress` |
| `subtopicApi.getCurrentSubtopic(...)` | GET | `/api/subtopics/:topicId/current` |
| `contentApi.generate(...)` | POST | `/api/content/generate` |
| `quizApi.submit(...)` | POST | `/api/quiz/submit` |
| `graphApi.getStudentGraph(...)` | GET | `/api/graph/:studentId` |
| `graphApi.getRecommendations(...)` | GET | `/api/graph/:studentId/recommendations` |

## Key Features

- **Adaptive quiz generation** — content adapts to student mastery and past mistakes via Claude AI
- **Subtopic progression** — subtopics unlock only after achieving >= 0.6 mastery
- **Knowledge graph** — force-directed visualization of topic relationships and mastery
- **Chemistry notation** — renders subscripts, superscripts, reaction arrows, Greek letters
- **Persistent sessions** — student state survives page refreshes via localStorage
- **Class level switching** — toggle between Class 11 and Class 12 curriculum from the navbar

## Notes

- The `routeTree.gen.ts` file is auto-generated by the TanStack Router Vite plugin on every dev start — do not edit it manually.
- The backend must be running and reachable at `VITE_API_URL` for any API calls to work.
- Signing out clears the Zustand store and localStorage, returning to the entry screen.
